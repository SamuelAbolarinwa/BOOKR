# BOOKR 📚⚡
> **The Financial Operating System for Student Entrepreneurs**

BOOKR is a hybrid mobile app engineered specifically for university founders, campus freelancers, and side-hustlers. It simplifies bookkeeping, separates personal vs. hustle cash flow, automates mobile invoicing with peer-to-peer payment links, and provides one-click financial exports for campus pitch competitions and micro-grants.
